Descripción General
¿Qué es UAFLOW / UAHUB?
Aplicación híbrida de escritorio y móvil para controlar, autorizar y registrar despachos de combustible en estaciones de servicio.

Autorización

Controla el inicio de cada carga desde la aplicación, con confirmación en tiempo real desde la consola TCP/IP.

Control de Importe

Despacho por monto en pesos, por litros exactos o llenado completo del tanque.

Trazabilidad

Registro completo de cada despacho con folio, litros, importe, producto y estatus consultable en historial.

Módulo 1
Despacho de Combustible
Flujo guiado de 3 pasos para seleccionar, autorizar y confirmar cada carga.
1

Selección de dispensario, producto y tipo

El operador elige el dispensario disponible, el producto (Magna, Premium, Diésel) y el tipo de despacho: por importe ($), por litros o llenado completo.

2

Autorización y surtido en tiempo real

Se envía la autorización a la consola TCP/IP. Al descolgar la manguera, la pantalla muestra litros e importe actualizándose en vivo junto con el indicador visual del tanque.

3

Ticket de despacho

Al finalizar el surtido se muestra el resumen completo: folio, dispensario, producto, litros, importe y precio. El ticket puede imprimirse al instante.

Surtido en Tiempo Real
Monitoreo del llenado
Mientras el combustible fluye, la aplicación refleja el avance de forma visual e inmediata.

Indicador de tanque

El nivel sube en tiempo real con el color del producto seleccionado.

✓

Litros surtidos en vivo

Contador actualizado constantemente desde la consola del dispensario.

✓

Importe equivalente

Muestra simultáneamente litros e importe en pesos conforme avanza la carga.

✓

Preset visible

El monto programado se muestra debajo del tanque como referencia durante el surtido.

✓

Cierre automático

Al colgar la manguera, el sistema detecta el fin del surtido y pasa al ticket.

Módulo 2
Historial de Cargas
Consulta los registros históricos de despachos filtrando por dispensario y producto.
1

Seleccionar dispensario

Elige el dispensario del que deseas consultar el historial. Se muestra el conteo total y la lista con scroll.

2

Elegir producto

Selecciona el tipo de combustible (Magna, Premium, Diésel) para acotar los resultados.

3

Resultados en tarjetas

Cada despacho muestra folio, hora, cantidad e importe. Permite reimprimir el ticket.

Módulo 3
Configuración
Panel protegido por contraseña que centraliza todos los parámetros del sistema.

Conexión TCP / IP

IP y puerto de la consola de dispensarios. Interfaz de comunicación configurable.

URL de APIs

Dirección completa de la API de backend (registro de autorizaciones, historial, impresiones).

Límites de importe y litros

Montos máximos por despacho para importe en pesos y volumen en litros.

Parámetros de dispensarios

Cantidad de dispensarios y numeración personalizada. Ajuste de decimales de cantidad.

Windows y Android
La interfaz se adapta automáticamente al tamaño de pantalla sin cambios de funcionalidad.

Windows (escritorio)

Navegación lateral fija, tarjetas de historial en múltiples columnas, campos amplios. Botón de configuración anclado al fondo de la barra lateral.

Android (móvil)

Menú desplegable tipo hamburguesa, cards de historial en 2 columnas, botones de navegación reorganizados para uso táctil cómodo.

Impresión nativa

En Android usa la impresora nativa del sistema operativo. En Windows puede redirigir al navegador para impresión estándar.

Acceso protegido

La configuración requiere contraseña. El menú de navegación se bloquea durante un despacho activo para evitar interrupciones.
